# IT Support Automation Toolkit

## Overview

The IT Support Automation Toolkit is a Python\-based monitoring and reporting solution that automates common IT support tasks.

The application monitors system health, generates Excel reports, uploads reports to AWS S3, maintains historical monitoring data, and visualizes system performance using Power BI.

## Features

### System Monitoring

- CPU utilization monitoring
- RAM utilization monitoring
- Disk usage monitoring

### Reporting

- Automated Excel report generation
- Historical performance logging
- CSV\-based trend tracking

### AWS Integration

- Automated Amazon S3 uploads
- Cloud\-based report storage

### Power BI Dashboard

- CPU monitoring dashboard
- RAM monitoring dashboard
- Disk monitoring dashboard
- Health status indicators
- Historical performance trends

## Project Workflow

1. Collect system health data.
2. Generate Excel reports.
3. Update historical monitoring logs.
4. Upload reports to AWS S3.
5. Visualize metrics in Power BI.
6. Automate execution using Windows Task Scheduler.
